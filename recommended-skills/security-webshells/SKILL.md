# SecLists Web-Shells

## Description

Web shell samples for detection and analysis: PHP, ASP, ASPX, JSP, Python, Perl shells. Use for security research and detection system testing.

**Source:** [SecLists/Web-Shells](https://github.com/danielmiessler/SecLists/tree/master/Web-Shells)
**Repository:** https://github.com/danielmiessler/SecLists
**License:** MIT

## When to Use This Skill

Use this skill when you need:
- Web shell detection testing
- Security monitoring validation
- Malware analysis
- IDS/IPS signature testing
- Forensics research

## Key Files in This Skill

- `references/Web-Shells/laudanum-1.0/` - Minimal multi-language shells (PHP/ASP/JSP/Perl and more)
- `references/Web-Shells/PHP/` - Common PHP web shells
- `references/Web-Shells/FuzzDB/` - FuzzDB web shell collection
- `references/Web-Shells/JSP/` and `references/Web-Shells/CFM/` - Java / ColdFusion shells
- `references/Web-Shells/WordPress/`, `references/Web-Shells/Vtiger/`, `references/Web-Shells/Magento/` - CMS-specific shells
