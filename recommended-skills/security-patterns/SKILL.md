# SecLists Pattern-Matching

## Description

Security pattern matching for code audit and content inspection: grep strings for source auditing, malicious-string signatures, PHP magic hashes, and error-message patterns.

**Source:** [SecLists/Pattern-Matching](https://github.com/danielmiessler/SecLists/tree/master/Pattern-Matching)
**Repository:** https://github.com/danielmiessler/SecLists
**License:** MIT

## When to Use This Skill

Use this skill when you need:
- Repository / source-code security auditing
- Detecting dangerous functions in code
- Scanning files for malicious strings or signatures
- PHP magic hash checks
- Error-message and known-vulnerable pattern matching

- `references/Pattern-Matching/grepstrings-basic.txt` - Grep patterns for security auditing
- `references/Pattern-Matching/repo-scan.txt` - Repository scanning patterns

- `references/Pattern-Matching/errors.txt` - Error message patterns
- `references/Pattern-Matching/php-magic-hashes.txt` - PHP magic hashes
- `references/Pattern-Matching/dangerous-functions-angular.txt` - Dangerous Angular functions
- `references/Pattern-Matching/pcap-strings.txt` - PCAP string patterns
- `references/Pattern-Matching/Source-Code-(PHP)/php-auditing.txt` - PHP source auditing patterns
