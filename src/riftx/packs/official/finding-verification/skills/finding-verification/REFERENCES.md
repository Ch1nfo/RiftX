# Finding Verification References

- Use the authoritative Reasoning Graph and immutable source snapshot, not the candidate narrative, as the reconstruction starting point.
- Verify attacker control, preconditions, every material path edge, security boundary, effective defenses, counterevidence, impact, source identity, and replayability.
- Distinguish evidence-complete candidate, disproven, duplicate, stale, unsupported, and unresolved outcomes.
- `propose_finding` creates a candidate only; it does not set Confirmed status.
- Confirmed Finding promotion remains behind the existing internal evidence and reproduction gate.
